# TITAN PULSE — Capacitor package

هذه الحزمة تحتوي نسخة الويب المعدلة لـ TITAN PULSE مع نظام الإشعارات، هوية التطبيق، وأصول Android الجاهزة للتركيب بعد إنشاء منصة Capacitor.

## تم التحقق منه
- كتل JavaScript داخل `www/index.html` تمر عبر `node --check` بدون أخطاء صياغة.
- بنية HTML الأساسية متوازنة، مع فحص للمعرّفات الداخلية وأصول الصور المحلية.
- نظام الإشعارات يطلب الصلاحية، ينشئ قناة، يرسل إشعارات بدء/اكتمال/فشل، ويجدول تذكير الغياب بعد 10 أيام.
- `smallIcon: 'ic_notification'` مربوط إلى مورد Android أحادي اللون وشفاف بدون النصوص، مناسب لظهور شعار TITAN PULSE داخل شريط الإشعارات.
- أيقونة التطبيق صُححت من الشعار المرفق: لا يوجد قصّ للنص أسفل الصورة، وتم تجهيز موارد launcher التقليدية وAdaptive Icon.

## تجهيز Android

من مجلد المشروع:

```bat
npm install
npx cap add android
npx cap sync android
```

الأيسر والأسهل: شغّل `scripts\\SETUP_ANDROID.bat` على Windows، وسيقوم بالخطوات السابقة ثم يركّب موارد الأيقونة والإشعار ويضمن صلاحيات Android المطلوبة.

للبناء:

```bat
cd android
gradlew.bat assembleDebug
```

## ملاحظة

مجلد `android/` وملف APK غير موجودين داخل هذه الحزمة، لأنهما يُولَّدان محليًا بواسطة Capacitor بعد تثبيت حزم npm. لذلك الحزمة الحالية مشروع Capacitor جاهز للتوليد والبناء، وليست APK جاهزة بحد ذاتها.

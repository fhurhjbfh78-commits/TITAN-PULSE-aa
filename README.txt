Android resource staging for TITAN PULSE.

Launcher:
- mipmap-*/ic_launcher.png = complete emblem launcher image, without the wordmark crop bug.
- mipmap-*/ic_launcher_round.png = same launcher image for round launcher slots.
- mipmap-*/ic_launcher_foreground.png = transparent foreground used by the Android 8+ adaptive icon.
- mipmap-anydpi-v26/ic_launcher.xml + ic_launcher_round.xml are generated by SETUP_ANDROID.bat.

Notification:
- drawable/ic_notification.png and drawable-*/ic_notification.png = white/transparent emblem-only small icon.
- The lower TITAN PULSE wordmark is intentionally removed because Android small notification icons need a compact foreground mark.
